🚀 GET STARTED IN 3 STEPS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Setup Prerequisites (5 minutes)
────────────────────────────────────────
1. Create MongoDB Atlas account (free) at https://mongodb.com/cloud/atlas
2. Create a free cluster and get connection string
3. Get OpenRouter API key from https://openrouter.ai

STEP 2: Configure Backend (2 minutes)
──────────────────────────────────────
1. Go to: backend/
2. Run: npm install
3. Create .env file with:
   - MONGODB_URI=your_connection_string
   - OPENROUTER_API_KEY=your_api_key
4. Run: npm run dev

Backend should start on http://localhost:5000

STEP 3: Configure Frontend (2 minutes)
───────────────────────────────────────
1. Go to: frontend/
2. Run: npm install
3. Run: npm start

Frontend should open at http://localhost:3000

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "MongoDB connection failed"
Solution:
  1. Check MongoDB URI in .env
  2. Verify IP is whitelisted in MongoDB Atlas
  3. Test connection string in MongoDB Compass

Problem: "OpenRouter API error"
Solution:
  1. Verify API key is correct
  2. Check account has credits
  3. Ensure API key is in .env

Problem: "Frontend can't reach backend"
Solution:
  1. Ensure backend runs on port 5000
  2. Check http://localhost:5000/api/health
  3. Verify CORS enabled in backend

Problem: "Port already in use"
Solution:
  Windows: netstat -ano | findstr :5000
  Mac/Linux: lsof -i :5000
  Then: kill the process or use different port
